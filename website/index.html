04 // INTEL

FAQ.

The short version. Everything else lives in the changelog on GitHub.

Is this actually free? What's the catch?

No catch. No ads, no trackers, no "premium tier," no data harvesting. 100% open source under GPL-3.0 — read every line yourself if you want.

Where does the music actually come from?

YouTube Music under the hood. Want studio-grade quality? Flip on the Monochrome source for lossless FLAC streaming.

Do I need root access or an account?

Nope and nope. Sidelaod the APK on anything running Android 8.0+ and hit play. That's it.

What about offline — does it actually work?

Cache songs and lyrics ahead of time. Preload mode resolves the next track before the current one ends — no buffering, no surprises, even on a plane.

How do I keep it updated?

The app checks for updates itself and points you to the latest GitHub release. Or just bookmark the releases page — your call.

Found a bug? Want a feature?

Drop an issue on GitHub or come vibe with us in the Telegram group. We actually read them.
