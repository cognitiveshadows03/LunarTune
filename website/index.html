04 // INTEL

FAQ.

Short answers. Full changelog ships with every release on GitHub.

Is LunarTune really free?

Yes — 100% free, no ads, no trackers, no premium tier. The source is open under GPL-3.0.

Where does the music come from?

LunarTune streams from YouTube Music, with lossless quality available through the Monochrome service.

Do I need root or a login?

Neither. Install the APK on Android 8.0+ and press play.

Does it work offline?

Yes. Cache songs and lyrics for offline playback, and preload mode keeps the next track ready.

How do I update?

Grab the latest stable from the GitHub releases page — the app's update check takes you there.

Found a bug / want a feature?

Open an issue on GitHub or hang out in the Telegram group.
